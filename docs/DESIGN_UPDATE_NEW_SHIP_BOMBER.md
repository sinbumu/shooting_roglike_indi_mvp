# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (신규 4번째 기체 추가)

> **문서 목적:** 테스터 피드백을 수용하여, 장판/폭발(지뢰) 트리에 특화된 4번째 플레이어블 기체 '붐바르딜로-크로코딜로'를 추가합니다. 스프라이트 에셋의 요구사항과 신규 고유 액티브 스킬의 로직을 명시합니다.

---

## 1. 🐊 신규 기체: '붐바르딜로-크로코딜로' 데이터 (`GameConfig.ts`)
스카웃(직사), 포트리스(방사), 헌터(유도)에 이어 **설치/폭발(지뢰)**을 기본으로 다루는 중장갑 폭격기 컨셉입니다.

- **기체 스탯 설정 (`SHIPS` 객체 추가):**
  ```typescript
  bomber: {
    id: 'bomber', 
    name: '붐바르딜로-크로코딜로', 
    icon: '🐊', 
    color: '#4d7c0f', // 국방색/늪지색
    desc: '중무장 폭격기. 매우 느리지만 압도적인 맷집과 폭발력을 자랑합니다. 중력 지뢰로 시작.',
    hpMul: 1.5,      // 포트리스(1.35)를 능가하는 최고 체력
    speedMul: 0.75,  // 가장 느린 이동 속도
    startingWeapon: 'mine', // 중력 지뢰 시작
    unlockCost: 2000,
    activeSkill: {
      id: 'carpetBombing', 
      name: '융단 폭격', 
      icon: '💥',
      cooldown: 20, 
      duration: 1.5, 
      bombCount: 12, 
      explodeRadius: 100
    },
  }
  ```

---

## 2. 💥 신규 액티브 스킬: [융단 폭격] 로직 (`GameState.ts`)
스페이스바(또는 스킬 버튼) 클릭 시 발동하는 붐바르딜로 전용 궁극기입니다.

- **발동 메커니즘:**
  - 스킬 발동 시 `duration`(1.5초) 동안 기체 주변 및 화면 내 무작위 좌표에 총 `bombCount`(12개)의 폭발 렌더링이 순차적으로 터집니다.
  - 각 폭발은 `explodeRadius`(100px) 내의 적에게 `PICKUPS.bombDamage`(또는 기체 레벨 비례 고정 데미지)만큼의 피해를 입히고, 해당 범위 내의 적 투사체를 소멸시킵니다.
  - **시각 효과:** 화면이 1.5초간 거칠게 흔들리며(Camera Shake), 연쇄 폭발 SFX가 겹쳐서 출력되어야 합니다.

## 3. 🎨 스프라이트 에셋 가이드 (`assets.ts` & 아트 리소스)
테스터가 첨부한 레퍼런스 이미지를 바탕으로 하되, 인게임 시점에 맞게 수정이 필요합니다.

- **요구사항:**
  - **발사 화염(Muzzle Flash) 제거:** 총구에서 불을 뿜는 이펙트는 인게임의 무기 투사체 렌더링과 충돌하므로, 완전히 정적인 상태의 기체 PNG로 저장해야 합니다.
  - **시점 및 톤앤매너:** 완벽한 Top-down(위에서 아래로 내려다보는) 시점 유지. 국방색(Military Green) 바탕에 악어 가죽 패턴(Scale texture)을 입힌 쌍발/네발 프로펠러 폭격기 디자인.
  - **Hitbox 대비 비율:** 기체의 날개폭이 넓은 편이므로, 날개 끝부분은 피격 판정(Hitbox)에서 제외됨을 유저가 인지할 수 있도록 코어(동체 중앙) 부분을 살짝 더 밝게 하거나 콕핏을 강조하는 디자인을 권장합니다.
