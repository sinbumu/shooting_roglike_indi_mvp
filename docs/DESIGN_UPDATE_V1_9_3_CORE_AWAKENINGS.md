# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (v1.9.3 신규 기체 코어 각성 추가)

> **문서 목적:** 50레벨 달성 시 제공되는 '코어 각성(Core Awakening)' 이벤트에서, 신규 기체 4종에게 구형 기체의 각성이 뜨는 하드코딩 버그를 픽스하고, 각 기체별 전용 코어 각성(A/B 루트)을 시스템에 추가합니다.

---

## 1. 🐊 붐바르딜로-크로코딜로 (폭격기) 코어 각성
기체의 아이덴티티인 '지뢰 매설'과 '융단 폭격' 중 하나를 극한으로 강화합니다.

*   **[각성 A] 네이팜 스톰 (Napalm Storm):**
    *   `융단 폭격(Spacebar)` 스킬의 폭발 횟수가 24회(2배)로 증가하며, 폭발이 일어난 자리에 5초간 적의 이동속도를 50% 늦추고 지속 피해를 입히는 **화염 장판(불길)**이 남습니다.
*   **[각성 B] 궤도 지뢰 부설기 (Orbital Minelayer):**
    *   기체가 이동하는 경로를 따라 **1.5초마다 무료 '중력 지뢰'가 자동 매설**됩니다. 또한 맵에 유지될 수 있는 지뢰의 최대 갯수 제한 상한이 사라집니다 (무한 매설).

---

## 2. 🤖 야차 (근접 카운터) 코어 각성
인파이팅의 생존력을 높일지, 카운터의 뽕맛을 극대화할지 선택합니다.

*   **[각성 A] 수라의 길 (Path of Asura):**
    *   `거합도(Spacebar)` 카운터에 성공할 경우, **스킬 쿨타임이 즉시 100% 초기화**됩니다. 유저의 피지컬만 받쳐준다면 적진 한가운데서 무한 카운터 참격 릴레이가 가능해집니다.
*   **[각성 B] 검강 (Sword Aura):**
    *   야차가 장착 중인 모든 '근접(Melee)' 무기가 타격될 때마다, 기체 전방으로 화면 끝까지 날아가는 **관통형 검기(Projectile)를 추가 사출**합니다. 근접 덱의 고질적인 사거리 문제를 완벽히 해결합니다.

---

## 3. 🛸 오버로드 (소환 지휘함) 코어 각성
군단의 물량을 늘릴지, 자폭 스킬의 화력을 키울지 결정합니다.

*   **[각성 A] 무한의 군단장 (Endless Legion):**
    *   소환수 최대 보유량이 추가로 +5 증가합니다. 또한 자폭 후 재조립되는 드론 중 20% 확률로 크기와 데미지가 3배인 **'엘리트 드론'**이 스폰됩니다.
*   **[각성 B] 핵분열 특이점 (Nuclear Fission):**
    *   `과부하 자폭(Spacebar)` 시 폭발 반경이 3배로 거대해집니다. 폭발 직후 중심부에 3초간 적들을 빨아들이는 **강력한 블랙홀(중력장)**이 생성되어 다음 자폭을 돕습니다.

---

## 4. 🩸 크림슨 팩트 (로우라이프) 코어 각성
극한의 줄타기를 보조하는 생존 특성 또는 데미지 상한 해제 특성입니다.

*   **[각성 A] 불사귀 (Immortal Demon):**
    *   체력이 1% 미만으로 떨어지는 치명적인 피해를 받으면 즉시 **5초간 무적 상태(Invincible)**가 되며, 이 동안 `혈사포(Spacebar)`의 쿨타임이 0초로 고정됩니다. (무적 쿨타임 60초)
*   **[각성 B] 피의 역류 (Blood Overdrive):**
    *   기본 패시브인 '잃은 체력 비례 데미지 증가'의 **최대 상한선이 300%에서 900%로 해제**됩니다. 대신 혈사포 적중 시 흡혈량이 절반으로 감소하여 더 극단적인 하이리스크 하이리턴을 요구합니다.

---

## 5. 🛠 구현 체크리스트 (코딩 에이전트용)
- [x] `GameConfig.ts` 또는 `CoreAwakenings.ts`: 기존 3기체만 있던 `CORE_AWAKENINGS` 데이터 구조에 `bomber`, `mech_yaksha`, `carrier_overlord`, `bio_crimson`의 A/B 분기 데이터를 추가합니다.
- [x] `LevelUpSystem.ts`: 플레이어가 50레벨 도달 시 팝업되는 코어 각성 모달에서, 하드코딩된 예전 기체 ID 풀을 사용하는 대신 `PLAYER.shipId`를 엄격히 매핑하여 해당 기체에 맞는 2개의 선택지만 띄우도록 분기(`switch` 또는 맵 객체)를 픽스합니다.
- [x] `GameState.ts` & `Renderer.ts`: 선택된 각성(Awakening) ID에 따라 자동 지뢰 매설(타이머 로직), 카운터 시 쿨타임 0 초기화, 검기(Projectile) 추가 사출, 치사량 데미지 시 무적 처리 등 각 기믹에 맞는 조건문을 추가합니다.
