# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (v1.9 신캐 3종 및 매트릭스 무기/패시브 추가)

> **문서 목적:** 극단적인 컨셉을 가진 4~6번째 플레이어블 기체 3종과, 이들과 시너지를 내는 3개의 신규 T1 무기가 9개의 T3로 뻗어나가는 '교차 조합(Matrix Crafting)' 트리를 구현합니다. 조합에 필요한 신규 패시브 아이템 정의도 포함됩니다.

---

## 1. 🤖 기체 1: '야차 (Yaksha)' (근접 카운터 메카)
- **패시브:** 'Ranged(원거리)' 태그 무기 발사 불가(장착만 가능). 'Melee(근거리)' 태그 무기의 타격 크기 1.5배, 데미지 1.5배 적용.
- **액티브 스킬: [거합도 - 발도술] (Spacebar)**
  - **발동:** 0.5초간 대기 동작(Stance) 진입. 
  - **카운터 성공 연출:** 대기 중 피격 시 즉시 데미지를 무효화하며, **기체의 테두리가 붉게 빛나는(Red Outline) 시각적 피드백** 출력.
  - **공격 판정:** 화면 전체가 아닌, **세로 1/4(25%), 가로는 전체(100%) 영역**을 휩쓰는 광역 참격 발생. (기체 약간 뒷부분부터 전방을 덮도록 BoxCollider 생성).
  - **피해량:** 카운터 성공 시 기본 스킬 피해량의 **1.5배**로 증폭되며, 현재 장착 중인 '근거리' 무기들의 총 레벨에 비례하여 추가 스케일링됨.

## 2. 🛸 기체 2: '오버로드 (Overlord)' (소환수 자폭 지휘함)
- **패시브:** 기체 본체의 모든 무기 데미지 90% 감소. 'Summon(소환)' 태그 무기 최대 보유량 +3, 소환수 기동/공격 속도 200% 증가.
- **액티브 스킬: [명령: 과부하 자폭] (Spacebar)**
  - **발동 연출:** 스킬 사용 시, 기체 전방 특정 거리(또는 마우스 커서 위치)에 **홀로그램 형태의 '자폭 명령 비콘(Beacon)' 마커가 시각적으로 생성**됨.
  - **메커니즘:** 필드의 모든 플레이어 소환수가 해당 비콘 위치로 즉시 이동(텔레포트)하여 거대한 광역 폭발(자폭)을 일으킴. 자폭 후 2초 뒤 소환수 즉시 재스폰.

## 3. 🩸 기체 3: '크림슨 팩트 (Crimson Pact)' (생체공학 버서커)
- **패시브:** 쉴드 최대치 0 고정, 회복 구슬 힐량 90% 감소. 잃은 체력 1%당 모든 딜량 및 투속 3% 증가(최대 300%).
- **액티브 스킬: [혈사포 (Blood Stream)] (Spacebar)**
  - **발동:** 현재 체력의 20% 즉시 소모. 
  - **다단히트 연출:** 단발성이 아닌, **2.5초간 기체 정면으로 길게 유지되는 굵은 피의 레이저(Beam) 발사.** 
  - **메커니즘:** 레이저가 유지되는 동안 닿는 적들에게 초당 N회의 다단히트(Multi-hit) 데미지를 주며, 피격된 적 1체당 기체 최대 체력의 1%씩 흡혈(생존기).

## 4. 🧬 신규 기본 패시브 9종 추가 정의 (`GameConfig.ts`)
T2, T3 조합에 필수로 요구되는 기본 스탯 패시브(Passive)들을 풀(Pool)에 추가합니다.
1. `티타늄 장갑`: 기체 최대 체력(Max HP) 증가
2. `추진기`: 이동 속도(Move Speed) 증가
3. `고폭약`: 폭발/타격 반경(Radius) 증가
4. `양자 배터리`: 무기 쿨타임(Cooldown) 감소
5. `확장 탄창`: 투사체 발사 수(Count) 증가
6. `나노 장갑`: 받는 피해 감소(Armor/Damage Reduction)
7. `재생 모듈`: 초당 체력 회복(HP Regen)
8. `치명타 렌즈`: 치명타 확률(Crit Chance) 증가
9. `가속 모터`: 투사체 속도(Projectile Speed) 증가

## 5. 🕸️ 신규 T1 무기 3종 및 매트릭스 교차 진화 트리
코딩 에이전트는 아래의 조합식을 `GameConfig.ts`의 `EVOLUTIONS` 데이터에 반영해야 합니다.

### [T1] 플라즈마 채찍 (Plasma Whip - 근거리)
- + `빔 소드` = **[T2] 궤도 전기톱** (+ `티타늄 장갑` = **[T3] 명왕의 톱니**)
- + `호밍 미사일` = **[T2] 마그네틱 훅** (+ `추진기` = **[T3] 중력 닻**)
- + `중력 지뢰` = **[T2] 진동 채찍** (+ `고폭약` = **[T3] 지각 절단기**)

### [T1] 스파이더 마인 (Spider Mine - 소환)
- + `스웜 드론` = **[T2] 요격기 편대** (+ `양자 배터리` = **[T3] 프로토콜: 둠스데이**)
- + `가틀링 건` = **[T2] 자동 포탑** (+ `확장 탄창` = **[T3] 궤도 폭격 신호소**)
- + `빔 소드` = **[T2] 톱니 드론** (+ `나노 장갑` = **[T3] 아이언 메이든 군단**)

### [T1] 핏빛 쐐기 (Blood Spike - 발사체, 체력 1% 소모)
- + `방어막 생성기` = **[T2] 착취의 오라** (+ `재생 모듈` = **[T3] 선혈의 처형대**)
- + `스프레드` = **[T2] 출혈 폭발** (+ `치명타 렌즈` = **[T3] 블러드 노바**)
- + `호밍 미사일` = **[T2] 피의 추적자** (+ `가속 모터` = **[T3] 흡혈 박쥐 떼**)
