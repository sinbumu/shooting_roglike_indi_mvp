# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (v1.7.5 경험치 곡선 및 필터링 폴리싱)

> **문서 목적:** 잦은 레벨업으로 인한 게임 템포 끊김 현상을 해결하기 위해 경험치 요구량 곡선을 재설계하고, 솔라 랜스(빔 무기)의 비호환 어픽스 필터링 및 UI 디테일을 보완하는 작업 지시서입니다.

---

## 1. 📈 경험치(EXP) 요구량 곡선 재설계 (Pacing)
**이슈:** 후반부 몹 처치로 얻는 경험치가 폭증하여 레벨업 창이 너무 자주 팝업됨. 전투의 흐름이 끊기고 쇼핑 빈도가 높아짐.

- **[x] 지수 함수(Exponential) 곡선 도입 (`GameConfig.ts`):** 
  - `LEVELING.expForLevel` 공식을 수정하여 초반(1~10레벨)의 빠른 템포는 유지하되, 후반부 요구량을 급격히 늘립니다.
  - **수정 제안식:** 기존 다항식 공식 대신, 레벨에 비례해 요구량이 지수적으로 증가하는 방식을 곱해줍니다.
  - 예시 공식: 
    $$ Base = 8 + (level \times 3) + (level / 5)^2 $$
    $$ Exp = Base \times (1.02)^{level} $$
  - 이 공식을 적용하면 50레벨 부근에서는 약 2.7배, 100레벨 부근에서는 약 7배 이상 요구량이 늘어나 레벨업 빈도가 안정화됩니다.

---

## 2. 빔(Beam) 무기 어픽스 필터링 추가
**이슈:** 솔라 랜스는 투사체가 날아가는 형태가 아닌 `speed: 0`의 즉발형 빔 무기임에도, '투사체 속도'나 '분열' 같은 무의미한 옵션이 등장함.

- **[x] `solance` 비호환 태그 추가 (`GameConfig.ts` & `LevelUpSystem.ts`):** 
  - `WEAPONS.solance` 데이터에 `tags: ['beam']` 또는 `tags: ['aura']`를 추가합니다.
  - v1.7.2 핫픽스에서 구현될 **'투사체 속도, 분열, 연쇄' 옵션 블랙리스트 로직**에 솔라 랜스도 반드시 포함되도록 처리하여 꽝 카드를 원천 차단합니다.

---

## 3. 텍스트 직관성 및 UI 개선
**이슈:** 어픽스의 작동 방식이 직관적이지 않고, 클리어 화면에서 버전을 확인할 수 없어 QA 파악이 어려움.

- **[x] '연쇄(Chain)' 어픽스 텍스트 수정 (`GameConfig.ts`):** 
  - 스플래시 폭발인지 체인 라이트닝인지 헷갈리는 텍스트를 명확히 수정합니다.
  - 기존: `명중 시 가까운 적에게 전이`
  - 변경: `명중 시 주변 적에게 번개처럼 튕기며 전이(체인)`
- **[x] 결과창(Mission Clear / Game Over) 버전 표기 (`UI.ts`):** 
  - 게임 종료 후 뜨는 결과 화면의 **우측 상단 모서리**에 현재 게임 버전(예: `v1.7.5`)을 작은 폰트로 렌더링하여, 유저 스크린샷 제보 시 버전을 즉각 파악할 수 있도록 추가합니다.
