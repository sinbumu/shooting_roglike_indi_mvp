# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (v1.12.0 공허의 모디파이어 & 섀도우 컴뱃)

> **문서 목적:** 3분 압축 파밍 스테이지인 '심연 강하'에 다회차 맵핑(Mapping)의 재미를 부여하는 '공허의 모디파이어(크래프팅)' 시스템과, 엔드게임 유저의 거울 치료를 담당할 '도플갱어 난입(섀도우 컴뱃)' 시스템을 도입합니다. 신규 시스템인 만큼 직관적인 UI/UX 구현에 초점을 맞춥니다.

---

## 1. 🗺️ 공허의 모디파이어: UI/UX 및 크래프팅 설계
플레이어가 심연 강하 맵에 리스크를 부여하고 보상 배율을 높이는 '맵 크래프팅' 인터페이스입니다.

### A. UI 레이아웃 및 조작 흐름 (`UI.ts`)
- **진입:** 격납고에서 `심연 강하(blitz)` 스테이지를 선택하고 [출격]을 누르면, 바로 게임이 시작되지 않고 **[공허의 맵 크래프팅] 모달**이 팝업됩니다.
- **좌측 패널 (현재 맵 상태):**
  - 상단: `[현재 보상 배율: +XXX%]` (크게 강조, 텍스트 색상 황금색)
  - 중단: 현재 맵에 부여된 **모디파이어 목록 (최대 4개)**.
    - *시각적 구분:* 접두어(적 강화)는 붉은색 텍스트, 접미어(환경 제약)는 보라색 텍스트로 렌더링하여 맥락을 직관적으로 전달합니다.
- **우측 패널 (조작부):**
  - **[변이 굴림 (Reroll)] 버튼:** 소모 크레딧(예: 1,000c) 명시. 클릭 시 좌측의 모디파이어 목록이 슬롯머신처럼 빠르게 회전(또는 페이드 인/아웃)하며 변경됩니다. 
  - *효과음:* 묵직한 기계음이나 마법석이 부딪히는 찰진 사운드(SFX) 필수.
  - **[이대로 출격 (Launch)] 버튼:** 현재 세팅된 리스크를 감수하고 게임을 시작합니다.

### B. 모디파이어 데이터 풀 (`GameConfig.ts`)
`MODIFIERS` 객체를 신설하고 아래 데이터를 추가합니다.
- **[접두어 - 적 강화]**
  - `mod_haste`: 일반 적 이동속도 +40% (보상 배율 +50%)
  - `mod_swarm`: 일반 적 스폰량 +100% (보상 배율 +80%)
  - `mod_unyielding`: 보스 체력 +150% (보상 배율 +100%)
- **[접미어 - 환경/제약]**
  - `mod_exhaust`: 기체 무기 쿨타임 +25% (보상 배율 +80%)
  - `mod_eclipse`: 시야 300px 제한 (암흑) (보상 배율 +120%)
  - `mod_minefield`: 맵 전체 무작위 위치에 지뢰 지속 생성 (보상 배율 +100%)
  - `mod_mirror`: **(히든) 2분 30초에 도플갱어 확정 난입** (보상 배율 +200%)

## 2. 👥 섀도우 컴뱃: 도플갱어(Nemesis) 시스템 (`GameState.ts` & `Renderer.ts`)
현재 플레이어의 빌드를 완벽히 복사하여 공격해 오는 히든 보스입니다.

### A. 스폰 및 렌더링
- **조건:** 심연 강하 스테이지 2분 30초에 `mod_mirror`가 있거나 5% 확률로 난입.
- **외형:** 플레이어와 완벽히 동일한 기체 스프라이트를 사용하되, `tint: 0x800080` (어두운 보라색)을 씌우고, 꼬리 쪽에 붉은 잔상(Trail) 파티클을 남겨 위압감을 줍니다.

### B. 빌드 복사(Copy) 메커니즘
- 스폰되는 순간, `PLAYER.weapons` 배열에 있는 무기 ID와 현재 레벨(T1~T3) 데이터를 해당 도플갱어 `Enemy` 객체의 내부 속성으로 **깊은 복사(Deep Copy)**합니다.
- `GameState.ts`의 전투 루프 내에 도플갱어 전용 무기 발사 로직을 추가합니다. 
  - 플레이어가 사용하는 `fireWeapon` 함수를 재활용하되, `isEnemy: true` 플래그를 넘겨 투사체의 피격 판정(충돌체)이 플레이어를 향하도록 설정합니다. (데미지는 플레이어 체력 스케일에 맞게 일괄 15~25 사이로 보정)

### C. 전리품
- 도플갱어 처치 시 일반 보석 대신, **[공허의 보급상자]**라는 전용 픽업 아이템(황금색 테두리의 상자 스프라이트)이 확정 드롭됩니다.
- 획득 시: 즉시 퀀텀 큐브 크래프팅(어픽스 부여) 1회 제공 + 판테온 포인트 +2 즉시 획득.
