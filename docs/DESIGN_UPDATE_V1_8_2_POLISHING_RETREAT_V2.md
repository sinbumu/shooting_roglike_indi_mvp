# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (v1.8.2 레벨업 템포, 최적화 및 편의성 폴리싱 V2)

> **문서 목적:** 플레이 테스트를 거쳐 확인된 템포 저하(과도한 레벨업 팝업), 후반부 불사신 문제(아이템 과다 드랍), 프레임 저하(최적화), 공허의 제단 연출/버그, 그리고 ESC 메뉴의 중도 포기(부분 보상) 기능을 추가하기 위한 코딩 에이전트용 작업 지시서입니다.

---

## 1. 📈 레벨업 몰아치기 (Batch Leveling) 시스템 수정
**이슈:** 경험치 곡선을 수정했음에도 80~90레벨 도달 시 레벨업 모달이 너무 자주 떠서 게임의 흐름이 툭툭 끊김. 단, 몰아치기를 너무 일찍 시작하면 초반 빌드업이 안 되어 생존이 불가능함.

- **[ ] 레벨업 UI 팝업 로직 수정 (`LevelUpSystem.ts`):** 
  - **1~15레벨 구간:** 초반 빌드업의 안정성을 위해, 기존과 동일하게 레벨업마다 즉시 3선택지 창이 팝업됩니다.
  - **16레벨 이후:** 레벨이 오르더라도 즉시 창이 뜨지 않고 내부적으로 `pendingLevelUps` 스택만 쌓입니다. 
  - 플레이어 레벨이 **5의 배수(20, 25, 30...)에 도달했을 때만** 모달이 팝업되며, 쌓여있던 `pendingLevelUps` 횟수만큼 연달아 선택지를 고르도록 루프(Loop) 로직을 구현합니다.
  - 이를 통해 초반 생존력을 보장하고, 후반 전투의 흐름을 길게 유지하여 쇼핑하듯 한 번에 빌드를 완성하는 쾌감을 줍니다.

---

## 2. 💊 다이내믹 아이템 드랍 스케일링 (Dynamic Drop Rate)
**이슈:** 후반부에 몹팩(Mob Pack)이 엄청나게 늘어나면 회복 아이템이 끝없이 쏟아져 플레이어가 불사신이 됨. 몹 수를 줄이지 않고 해결 필요.

- **[ ] 적 개체수 반비례 드랍률 적용 (`GameState.ts`):** 
  - 화면에 존재하는 적의 수(`enemies.length`)가 많아질수록 개별 적의 아이템 드랍 확률을 낮추는 보정 공식을 적용합니다.
  - 예시 수식 (수학적 보정): 
    $$ AdjustedDropChance = \frac{BaseDropChance}{\max(1, \sqrt{EnemyCount / 10})} $$
  - 이 공식을 적용하면 몹팩이 폭증해도 전체적인 맵의 아이템 드랍 총량은 일정하게 유지됩니다.
- **[ ] 아이템 질(Quality) 상향 (`GameConfig.ts`):** 
  - 드랍률이 낮아지는 후반부를 대비해, 게임 진행 시간(Time)에 비례하여 `PICKUPS.healAmount`와 `PICKUPS.bombDamage` 수치가 점진적으로 스케일링(강화)되도록 로직을 추가합니다.

## 3. ⚡ 대규모 몹팩 프레임 드랍 최적화 (Optimization)
**이슈:** 화면에 몹과 투사체가 가득 찰 때 심각한 프레임 저하(Lag) 발생.

- **[ ] 렌더링 및 연산 최적화 지시 (`Renderer.ts`, `GameState.ts`):**
  - 코딩 에이전트는 다음 최적화 기법 중 누락된 것을 찾아 코드를 리팩토링해야 합니다.
  - **오브젝트 풀링(Object Pooling):** 몹, 투사체, 파티클, 데미지 텍스트를 매번 `new`로 생성/삭제(`splice`)하지 않고, 비활성화 후 재사용하는 풀(Pool) 구조로 변경.
  - **공간 분할(Spatial Hashing / Grid):** 적과 투사체의 충돌 판정(Collision Detection) 시 모든 객체를 순회하는 병목 현상을 방지하기 위해, 화면을 그리드로 나누어 인접한 객체끼리만 거리를 계산하도록 충돌 연산 최적화 적용.

## 4. 🩸 공허의 제단 연출 강화 및 종료 버그 픽스
**이슈:** 제단이 밋밋하게 스폰되며, 기믹 완료 후에도 사라지지 않고 맵에 남아있음.

- **[ ] 제단 스폰 연출 추가 (`Renderer.ts`):** 
  - 공허의 제단이 스폰될 때 단순히 뿅 나타나지 않고, 바닥에서 솟아오르는 애니메이션과 함께 짙은 보랏빛 안개(Smoke) 파티클이 터지는 으스스한 연출(Spooky FX)을 추가합니다.
- **[ ] 제단 디스폰(Despawn) 로직 추가 (`GameState.ts`):** 
  - 제단의 기믹(엘리트 몹 무리 처치 및 보상 선택 창 닫힘)이 완전히 종료되면, 제단 오브젝트의 상태를 `active = false`로 변경하거나 맵 배열에서 제거하여 필드를 깔끔하게 비워야 합니다.

## 5. 🏳️ 중도 포기 (Retreat) 및 부분 보상 시스템
**이슈:** 초반 빌드가 망해서 재도전하고 싶을 때, 죽거나 클리어할 때까지 강제로 기다려야 보상을 받을 수 있음 (강제 종료 시 0 보상).

- **[ ] ESC 일시정지 메뉴 '격납고 귀환' 버튼 추가 (`UI.ts`):**
  - 일시정지 창에 기존 [계속하기], [다시하기] 버튼과 함께 **[격납고 귀환 (중도 포기)]** 버튼을 추가합니다.
- **[ ] 부분 보상 정산 로직 (`GameState.ts` & `Meta.ts`):**
  - 귀환 버튼 클릭 시 "정말 귀환하시겠습니까? 현재까지 획득한 크레딧은 저장됩니다."라는 확인 모달을 띄웁니다.
  - 수락할 경우 즉시 게임을 종료 처리(Game Over와 유사한 처리)하며, **그 시점까지 획득한 점수 비례 크레딧과 보석을 온전히 정산하여 메타 데이터에 저장**한 뒤 로비로 돌아갑니다. (단, 미션 클리어 보너스 등은 제외)
