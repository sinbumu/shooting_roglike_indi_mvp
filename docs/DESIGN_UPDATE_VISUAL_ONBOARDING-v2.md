# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (시각적 직관성 & 온보딩 UX 개선) v2

> **문서 목적:** 플레이어 피드백을 반영하여 게임 내 위험도(데미지)의 시각적 인지성을 높이고, 무기고(Arsenal) 등 후반 콘텐츠에 대한 설명을 보강하여 초보 유저의 학습을 돕습니다.
> **업데이트 내역 (v2):** 보스 탄막 시인성 강화(흰색 코어+보라색 테두리) 및 아스널 프리뷰에 무기 강화(+10%) 안내 추가.

---

## 1. 🎨 위험도 기반 색상 코딩 (Color-Coded Danger)
**이슈:** 적 기체나 탄막의 데미지가 각각 다름에도 색상 기준이 통일되지 않아, 플레이어가 직관적으로 위험도를 파악하기 힘듦.

### 1-1. 데미지 구간별 색상 표준화 (`GameConfig.ts`)
- **기능:** 적의 `contactDamage` 및 보스의 `bulletDamage` 수치를 기준으로, 색상(Color Hex)을 엄격하게 분류하여 적용합니다.
- **색상 팔레트 가이드 (추천안):**
  - 🟢 **Low (15 미만):** `#4ade80` (초록/파랑계열) - 스쳐도 치명적이지 않은 잡몹 (예: 드론, 지그재그)
  - 🟠 **Medium (15 ~ 24):** `#f97316` (주황계열) - 연속으로 맞으면 위험한 적 (예: 대셔, 러셔, 실더, 텔레포터)
  - 🔴 **High (25 이상):** `#ef4444` (빨강계열) - 탱커형 적이나 닿으면 뼈아픈 타격 (예: 탱크)

### 1-2. 보스 탄막 시인성 극대화 (Boss Projectiles)
- 🟣 **Fatal / Boss (30 이상 또는 보스 탄막):** 단순한 단색 렌더링을 벗어나, **안쪽(Core)은 하얗게 빛나고 바깥쪽 테두리(Outline)는 보라색/마젠타색(`#c084fc`)**으로 처리합니다.
- **효과:** 배경이 어두운 우주 맵에서 치명적인 탄막이 뚜렷하게 분리되어 보여, 유저의 '억울한 피격' 경험을 크게 줄여줍니다.

## 2. 📖 아스널(무기고) 빈 화면 설명 보강 (Onboarding UX)
**이슈:** Tier 3 무기가 없을 때 무기고 창이 열리면 "Tier 3 무기가 없습니다"라는 텍스트만 덩그러니 있어, 큐브의 가치와 시스템의 목적을 알 수 없음.

### 2-1. 미해금 상태에서의 '프리뷰(Preview)' 제공
- **기능:** Tier 3 무기가 없어 크래프팅이 불가능한 상태라도, 닫기 버튼 위에 퀀텀 큐브로 할 수 있는 **매력적인 결과물**을 예고(Teasing)하는 텍스트와 UI를 배치합니다.
- **수정안 (`UI.ts` - Arsenal 렌더링 부분):**
  - 기존 텍스트: "Tier 3 무기가 없습니다. 조합 후 다시 오세요."
  - **변경 텍스트:** 
    ```text
    [!] 퀀텀 큐브 크래프팅 비활성화
    현재 장착 중인 종결(Tier 3) 무기가 없습니다.
    
    💡 Tier 3 무기를 획득하면 퀀텀 큐브를 소모하여 아래의 특수 능력을 부여할 수 있습니다:
    ✳️ [분열] 투사체 분열
    ➡️ [관통] 관통 횟수 증가
    🔗 [연쇄] 적중 시 전이
    💪 [강화] 무기 기본 데미지 영구 +10% 증가
    ```
- **기대 효과:** 유저가 '왜 Tier 3를 만들어야 하는지', '큐브를 왜 모아야 하는지' 스스로 깨닫고 목표를 설정하게 만듭니다.
