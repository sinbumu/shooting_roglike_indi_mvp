## 2. 죽은 데이터 정리 (Dead Content)
- [x] `nebula_clear` 업적 삭제 (`GameConfig.ts`, `Meta.ts`): 과거 스테이지 개편 시 삭제된 '성운 전선' 관련 업적인 `nebula_clear` 데이터가 남아 영구히 달성 불가능한 상태입니다. 해당 데이터를 삭제하고, 기존 유저 세이브 파일 로드 시 안전하게 무시되도록 처리합니다.

## 3. 트래퍼(Trapper) 기믹 재설계 (Arena Trap)
**이슈:** 트래퍼의 레이저 펜스가 화면 위쪽(y=170 부근)에 고정 생성되어, 단순히 상단의 지뢰밭처럼 작동하며 기획 의도인 '강제 투기장' 역할을 하지 못함.

- [x] 플레이어 기준 펜스 전개 (`GameState.ts`):
  - 트래퍼가 스폰되어 자리를 잡고 말뚝(Pylon)을 사출하는 시점의 **'플레이어(Player)의 현재 x, y 좌표'**를 펜스의 중심점으로 삼도록 타겟팅 로직을 수정합니다.
  - 이를 통해 플레이어는 스폰 즉시 자신이 위치한 곳에서 사각형 펜스에 갇히게 되어, 기획 의도대로 좁은 공간 안에서 탄막을 회피하는 플레이를 강제받게 됩니다.

## 4. v1.6 기능 버그 및 UX 픽스
- [x] 참격(근접 무기) 방향 고정 버그: `blade`, `beamSword` 등의 참격 판정 및 렌더링이 항상 위쪽만 향하는 문제를 수정합니다. 조이스틱이나 방향키의 입력 벡터인 `PLAYER.lastAim`을 참조하여 참격 이펙트와 충돌체(Hitbox)에 **회전(Rotation)**을 적용해야 합니다.
- [x] 수집 드론 타겟팅 누락: 수집 드론이 경험치(`GEM`)만 당겨오는 현상을 수정하여, 폭탄, 퀀텀 큐브, 회복약 등 `PICKUPS` 배열 내의 모든 아이템을 당겨오도록 로직을 확장합니다.
- [x] 신규 무기 스킨 누락 (`GameConfig.ts`): `PROJ_SKINS` 객체에 신규 T1 무기인 플라즈마 블레이드(`blade`)와 중력 지뢰(`mine`)의 블랙마켓 스킨을 최소 1종씩 추가합니다 (예: 붉은색 참격, 맹독 지뢰 텍스처).
- [x] HUD 드론 장착 표기 (`UI.ts`): 인게임 화면에서 기체 옆 작은 원으로만 표시되는 드론을, 상단 HUD(체력 바 아래 등)에 **장착 중인 드론 아이콘** 형태로 명시하여 유저가 명확히 인지하게 합니다.
- [x] 드론 강화 UI 키보드 접근성: 격납고의 드론 업그레이드 UI(`drone-up` `span`)가 포커스를 받지 못하는 문제를 해결하기 위해, 해당 요소를 `<button>` 태그로 변경하거나 `tabindex="0"` 속성을 추가하여 키보드 방향키 조작에 대응시킵니다.
