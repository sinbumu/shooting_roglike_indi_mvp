# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (인게임 패치 노트 시스템)

> **문서 목적:** 테스터들이 깃허브 외부로 나가지 않고도 게임 내에서 직관적으로 최신 변경 사항을 확인할 수 있도록, 정적 데이터 기반의 인게임 패치 노트(Changelog) UI를 추가합니다.

---

## 1. 📝 정적 데이터 기반 패치 로그 관리
**이슈:** 매번 테스터에게 커밋 로그를 확인하라고 안내하기 번거로움.

### 1-1. `PatchNotes.ts` (또는 JSON) 파일 분리
- **기능:** 게임 업데이트 시 커밋 단위로 추가할 수 있는 간단한 데이터 구조를 만듭니다. 과거 내역은 소급 적용하지 않고, 이 시스템이 도입된 시점(현재)부터 기록을 누적합니다.
- **데이터 구조 예시 (`src/PatchNotes.ts`):**
  ```typescript
  export interface PatchNote {
    version: string;
    date: string;
    changes: string[];
  }

  // 항상 최신 패치가 배열의 첫 번째(index 0)에 오도록 작성하거나, 
  // 렌더링 시 UI에서 .reverse() 처리합니다.
  export const PATCH_NOTES: PatchNote[] = [
    {
      version: 'v1.1.0',
      date: '2026-08-14',
      changes: [
        '✨ [신규] 초반 레벨업 시 T1 신규 무기 확정 등장 (억까 방지)',
        '💄 [UI] 아스널(무기고) 빈 화면에 프리뷰 설명 추가',
        '🎨 [시각] 적 위험도(데미지)에 따른 색상 표준화 및 보스 탄막 시인성 강화',
        '🐛 [버그] 로비 복귀 시 크레딧 UI가 즉시 갱신되지 않던 문제 수정'
      ]
    },
    {
      version: 'v1.0.0',
      date: '2026-08-13',
      changes: [
        '🚀 로컬 MVP 및 엔드게임 심화 패치 적용 완료'
      ]
    }
  ];
  ```

## 2. 🖥️ 패치 노트 UI/UX 구현
**이슈:** 게임의 메인 흐름(격납고 세팅)을 방해하지 않으면서도 쉽게 접근할 수 있는 위치가 필요함.

### 2-1. 로비(Hangar) 진입 화면 아이콘 배치
- **기능:** 격납고 화면의 우측 상단이나 좌측 하단 구석에 작고 눈에 띄는 **[버전 정보 / 📝 패치 노트]** 버튼을 배치합니다.
- **표기:** 버튼 안에는 현재 최신 버전명(예: `v1.1.0`)이 텍스트로 노출되어, 유저가 누르지 않아도 버전이 올랐음을 인지할 수 있게 합니다.

### 2-2. 패치 노트 모달(Modal) 창
- **기능:** 버튼 클릭 시 게임 화면 중앙에 스크롤 가능한 모달창이 팝업됩니다.
- **레이아웃:**
  - 최신 버전이 가장 위에 오도록(내림차순) 렌더링합니다.
  - 각 버전의 `date`와 `version`을 헤더로 굵게 표시하고, `changes` 배열을 불릿 포인트(`-` 또는 `•`)로 나열합니다.
  - 변경점의 성격에 따라 아이콘(✨, 🐛, ⚖️, 🎨)을 말머리에 달아주면 가독성이 더욱 좋아집니다.
