# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (정밀 조작 & 이동 편의성 개선)

> **문서 목적:** 플레이어의 조작 피드백("천천히 움직이기")을 반영하여, 촘촘한 탄막을 미세하게 회피할 수 있는 정밀 조작(Precision Movement) 기능을 추가합니다.
> **핵심 철학:** 슈팅 게임(탄막 슈팅)의 본질인 '한 끗 차이 회피'의 쾌감을 살리기 위해 입력 기기별(키보드/터치) 맞춤형 아날로그/저속 이동을 지원합니다.

---

## 1. ⌨️ 키보드: '정밀 비행(Focus)' 모드
**이슈:** 키보드(WASD/방향키) 입력은 0 아니면 1이므로 항상 최고 속도로만 이동해 미세 컨트롤이 어려움.

### 1-1. Shift 키 저속 이동
- **조작:** `Shift` 키를 누르고 있는 동안 발동.
- **기능:** 기체의 이동 속도가 기본 속도의 특정 비율(예: 40~50%)로 감소합니다.
- **시각적 피드백(선택):** Shift를 누를 때 기체 중앙에 작은 피격 판정(Hitbox) 점이 밝게 빛나거나, 엔진 추진체 이펙트가 작아져 '정밀 조작 중'임을 알리면 더욱 좋습니다 (고전 탄막 슈팅 스타일).

---

## 2. 📱 모바일(터치): 아날로그 가상 조이스틱
**이슈:** 모바일 가상 조이스틱이 드래그 거리와 무관하게 항상 100% 속도만 내고 있어 정교한 조작이 불가능함.

### 2-1. 드래그 거리에 비례한 속도 조절
- **조작:** 가상 조이스틱을 끄는(Drag) 거리에 따라 이동 속도를 세밀하게 조절.
- **작동 방식:**
  - 조이스틱의 중심부터 현재 터치 위치까지의 거리(Distance)를 계산.
  - 이 거리를 `JOYSTICK.radius`(최대 반경)로 나누어 **0.0 ~ 1.0 사이의 정규화된 강도(Magnitude)** 값 산출.
  - 최종 이동 속도 = `기체 최고 속도 × 강도(Magnitude)`
- **기대 효과:** 살짝 밀면 걷고, 끝까지 밀면 달리는 콘솔 게임 패드와 같은 부드러운 아날로그 감각 제공.

## 3. 🛠 구현 체크리스트 (개발 가이드)

- [x] **`GameConfig.ts` 수정:**
  - `PLAYER` 객체 내부에 정밀 비행 속도 배율 상수를 추가합니다. (예: `focusSpeedMul: 0.45`)
- [x] **키보드 입력 처리 (`main.ts` 등):**
  - `keydown`, `keyup` 이벤트에 `Shift` 키 상태(`isFocusing` 플래그)를 추적하는 로직을 추가합니다.
- [x] **조이스틱 입력 처리 (`UI.ts` 또는 컨트롤러 로직):**
  - 가상 조이스틱 드래그 시, 벡터의 정규화된 방향(x, y)뿐만 아니라 **입력 강도(magnitude, 0~1)** 값도 함께 `GameState`로 전달하도록 업데이트합니다.
- [x] **이동 로직 업데이트 (`GameState.ts`):**
  - 키보드 이동 시: `isFocusing`이 참이면 최종 속도에 `focusSpeedMul`을 곱합니다.
  - 조이스틱 이동 시: 최종 속도에 조이스틱 `magnitude`를 곱합니다.
