# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (v1.7.3 조준 메커니즘 및 UI 명확화)

> **문서 목적:** v1.7.2 핫픽스 진행과 병행하여, 테스터가 추가 제보한 무기 타겟팅 결함(V존 딜누수), 동형 무기 다중 장착 시 크래프팅 UI의 모호성, 그리고 실전 밸런스 수치를 즉각적으로 교정하기 위한 지시서입니다.

---

## 1. 🎯 제네시스(Genesis) V존 명중 결함 픽스
**이슈:** `targeted: true` 속성으로 적을 정확히 조준하지만, 2발의 탄환이 부채꼴(`spreadDeg: 10`)로 발사되어 크기가 작은 적의 좌우로 스쳐 지나가는 심각한 딜 누수 발생.

- **[x] 해결안 (`GameConfig.ts`):**
  - `WEAPONS.genesis.projectile`의 속성을 중앙 집중형으로 바꿉니다.
  - **옵션 A (단발 융합, 적용):** `count: 1`, `damage: 76` (기존 38 * 2), `spreadDeg: 0`.
  - 옵션 B (중앙 추가): `count: 3` / `damage: 26` — 미채택.

---

## 2. 🗗 다중 장착 무기 크래프팅 UI 가시성 개선
**이슈:** 같은 종류의 종결 무기(예: 제네시스)를 여러 슬롯에 장착했을 때, 크래프팅 강화나 어픽스 부여 선택지가 '몇 번 슬롯'의 무기에 적용되는지 분간할 수 없음.

- **[x] 해결안 (`UI.ts` & `LevelUpSystem.ts`):**
  - 동일한 ID가 2개 이상이면 제목·설명에 슬롯 번호 명시. 예: `[2슬롯] 제네시스 어픽스 부여` / `[3슬롯] 제네시스 크기 +15%`
  - 적용 로직도 `weaponSlotIndex`로 해당 슬롯만 강화.
  - HUD 무기 칸에 1-based 슬롯 번호 배지.

---

## 3. ⚖️ 프레데터 스웜 & 해머딘 실전 밸런스 상향
**이슈:** 종결(T3) 무기임에도 기믹의 한계로 인해 타 무기 대비 딜 기여도와 체감 성능이 떨어짐.

- **[x] 프레데터 스웜 상향 (`GameConfig.ts`):** `speed` 100 → **180**, `drop.seekSpeed` 110 → **200**.
- **[x] 해머딘(helix) 상향 (`GameConfig.ts`):** `explodeRadius` 62 → **85**, `cooldownMs` 700 → **580**.

---

## 4. 🏷️ 무기별 어픽스 블랙리스트 정교화
**이슈:** 기본 관통이 높은 레일건 계열에 또 관통 어픽스가 뜨는 등 '무의미한' 선택지 등장.

- **[x] 해결안 (`GameConfig.ts` `compatibleAffixes`):** `projectile.pierce >= 5`인 무기(레일건·제네시스·오메가·솔란스 등)에서 `pierce` 어픽스 제외.
