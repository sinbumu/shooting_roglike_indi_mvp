# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (격납고 드론 UI 개편)

> **문서 목적:** 로비(격납고) 화면의 공간 부족과 가시성 저하 문제를 해결하기 위해, 드론 선택 영역을 별도의 모달(Modal) 창으로 분리하고 메인 화면의 기체 선택 영역을 온전히 확보하기 위한 UI/UX 개선 지시서입니다.

---

## 1. 🖥️ 메인 로비(Hangar) 레이아웃 개편
**이슈:** 기체 선택 리스트와 드론 베이 리스트가 화면을 위아래로 나누어 차지하면서, 스크롤이 답답해지고 UI가 조잡해 보임.

### 1-1. 기체 선택 영역 원상 복구
- 기존에 드론 베이가 차지하던 세로 공간을 제거하고, 기체(Ship) 선택 리스트가 온전하게 화면 중심을 차지하도록 높이 및 스크롤 여백을 조정합니다.

### 1-2. 장착 드론 요약 뷰 (Summary) 및 진입 버튼 추가
- 드론 리스트 전체를 렌더링하는 대신, 메인 화면에는 **현재 장착 중인 드론 정보** 한 줄만 간략하게 표시합니다.
- **표시 예시:**
  - 장착 시: `현재 드론: 🧲 수집 드론 Lv.1`
  - 미장착 시: `장착된 드론 없음`
- 요약 뷰 영역 자체가 버튼 역할을 하거나, 영구 강화/블랙마켓 버튼이 있는 하단 메뉴 그룹에 **[드론 베이]** 버튼을 신설하여 클릭 시 전용 모달창이 열리도록 연결합니다.

---

## 2. 🗗 신규 '드론 베이(Drone Bay)' 모달 구현
**기능:** 드론의 구매, 업그레이드, 장착을 전담하는 독립된 팝업 창입니다.

### 2-1. 모달 렌더링 (`UI.ts`)
- **디자인 톤앤매너:** 영구 강화(Meta Upgrades)나 블랙마켓 모달과 동일한 팝업 템플릿을 사용합니다.
- **내용물:** 기존 메인 화면에 렌더링되던 드론 리스트 뷰(설명, 레벨, 구매/업그레이드 버튼, 장착 버튼 등)를 이 모달 내부로 완전히 이관합니다.
- **상태 동기화:** 모달 내부에서 드론을 변경하고 [닫기] 버튼을 누르면, 메인 로비 화면의 '장착 드론 요약 뷰' 텍스트가 즉각적으로 갱신되어야 합니다.
