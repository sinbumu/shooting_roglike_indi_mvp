# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (v1.9.2 레벨업 UI 직관성 개선)

> **문서 목적:** 무기 및 패시브의 종류와 조합식이 방대해짐에 따라 발생하는 '암기 진입장벽'을 해소하기 위해, 기존 3선택지 카드의 깔끔한 UI를 해치지 않으면서 시너지와 진화 가능성을 직관적으로 알려주는 시각적 힌트(테두리 발광 및 뱃지)를 도입합니다.

---

## 1. 🔲 테두리 발광 연출 (Border Glow)
선택지가 플레이어의 현재 덱(인벤토리)이나 기체 특성과 얼마나 강한 시너지를 내는지 카드 테두리의 빛깔로 직관적으로 알려줍니다.

- **[ ] 시너지 발광 (푸른색 아우라 - `Synergy Glow`):**
  - **조건:** 현재 플레이 중인 기체의 특화 태그(예: 야차의 `melee`, 오버로드의 `summon`)와 일치하는 무기/패시브가 등장했을 때.
  - **연출:** 카드 테두리에 은은하게 일렁이는 **푸른색(또는 기체 테마색) 네온 글로우 효과**를 부여합니다.
- **[ ] 진화 임박 (황금색 맥동 - `Evolution Ready`):**
  - **조건:** 해당 선택지를 고를 경우, 플레이어가 **현재 보유한 아이템과 결합하여 즉시 상위 티어(T2, T3)로 진화**할 수 있는 핵심 재료일 때.
  - **연출:** 카드 테두리가 **강렬한 황금색으로 빛나며 빠르게 맥동(Pulse)**하는 애니메이션을 적용하여, "이 카드는 무조건 집어야 한다"는 강력한 시각적 쾌감을 제공합니다.

---

## 2. 🧩 퍼즐 뱃지 시스템 (Puzzle Badge)
텍스트를 길게 늘어놓지 않고, 직관적인 미니 아이콘 하나로 '조합 가능성'을 암시합니다.

- **[ ] 조합 힌트 뱃지 렌더링 (`UI.ts`):**
  - **조건:** 해당 선택지가 플레이어의 인벤토리에 있는 무기/패시브 중 최소 1개 이상과 **동일한 조합식(Evolutions) 트리에 묶여 있을 경우** (즉시 진화가 아니더라도 나중을 위해 모아두면 좋은 파츠일 경우).
  - **연출:** 카드의 우측 상단 모서리에 작고 세련된 **'퍼즐 조각(🧩)' 또는 '링크(🔗)' 아이콘 뱃지**를 렌더링합니다. 
  - 이를 통해 유저는 텍스트를 읽지 않아도 "아, 이 카드는 내가 가진 덱의 조합 파츠구나"라고 쉽게 인지할 수 있습니다.

---

## 3. 🛠 구현 체크리스트 (코딩 에이전트용)
- [ ] `LevelUpSystem.ts`: `generateOptions` 함수에서 3개의 카드를 픽업할 때, 플레이어의 현재 인벤토리(`PLAYER.weapons`, `PLAYER.passives`) 및 기체 정보(`PLAYER.shipId`)를 대조하여 각 카드 객체에 `isSynergy`, `canEvolve`, `hasCombo` boolean 플래그를 연산하여 부여합니다.
- [ ] `UI.ts` (또는 UI 렌더러): 카드 렌더링 루프에서 위 플래그들을 검사하여 CSS 클래스(또는 Canvas 렌더링 속성)를 동적으로 할당합니다.
  - `canEvolve === true` ➡️ 황금색 맥동 테두리 애니메이션 적용.
  - `isSynergy === true` ➡️ 푸른색 은은한 테두리 아우라 적용.
  - `hasCombo === true` ➡️ 카드 우측 상단 절대 좌표에 퍼즐 뱃지 아이콘(`spr_badge_puzzle`) 오버레이 렌더링.
