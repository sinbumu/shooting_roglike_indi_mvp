# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (조작 편의성 & 액티브 스킬 & 크래프팅 UX)

> **문서 목적:** 로컬 MVP 완성 이후, 플레이어의 조작 경험(UX)을 개선하고 기체별 개성을 뚜렷하게 만들기 위한 3가지 핵심 개선안입니다.
> **핵심 철학:** 복잡한 UI를 덜어내어 직관성을 높이고, 키보드 단일 조작을 지원하며, 찰나의 피지컬 개입(액티브 스킬)으로 액션성을 더합니다.

---

## 1. 🛠️ 크래프팅(무기고) UX 전면 개편 (직관성 및 접근성 강화)
**이슈:** 기존 무기고 시스템이 특정 시간에 갑자기 팝업되거나 복잡한 화폐(큐브) 소모 UI를 가져, 처음 접하는 유저에게 흐름을 끊고 직관적이지 않게 느껴짐.

### 1-1. '화폐 누적형 상점'에서 '즉각적인 크래프팅 오브(Orb)' 방식으로 변경
- **개편 방향:** 별도의 '무기고(Arsenal)' UI 창을 아예 삭제하고, 플레이어에게 이미 익숙한 **'레벨업 3선택지' UX를 그대로 재활용**합니다.
- **작동 방식:** 
  - 보스 페이즈 전환이나 돌발 균열 엘리트가 '퀀텀 큐브(오브)' 아이템을 필드에 드랍합니다.
  - 플레이어가 이 큐브를 획득하면 즉시 게임이 일시정지되고 **[크래프팅 3선택지]**가 팝업됩니다.
- **크래프팅 3선택지 구성 (플레이어가 보유한 T3 무기 기반으로 자동 생성):**
  - 선택지 A: `[스타폴]에 무작위 어픽스 부여 (또는 리롤)`
  - 선택지 B: `[오메가 캐논] 기본 데미지 영구 +15% 증가`
  - 선택지 C: `[제네시스] 투사체 속도 +20% 증가`
- **기대 효과:** 복잡한 설명이나 상점 UI 없이, 기존 레벨업과 똑같은 감각으로 종결 무기를 깎아나갈 수 있어 학습 비용이 0에 가깝게 줄어듭니다.

## 2. ⚡ 기체별 고유 액티브 스킬 (Active Skills)
**이슈:** 자동 사격과 이동만으로는 위기 상황(보스 탄막, 텔레포터 기습)을 피지컬로 극복하는 쾌감이 부족함.

### 2-1. 액티브 스킬 시스템 도입
- **조작:** PC는 `Spacebar` (또는 `Shift`), 모바일은 우측 하단의 **반투명 스킬 버튼** 터치.
- **UI:** 기체 옆이나 HUD 하단에 스킬 쿨타임 게이지/아이콘 표시.

### 2-2. 기체별 스킬 디자인 (`SHIPS` 데이터에 추가)
- **스카웃 [위상 대시 / Phase Dash]**
  - **효과:** 바라보는(이동하는) 방향으로 짧은 거리 순간이동. 이동 중 완벽한 무적 판정.
  - **쿨타임:** 6초
  - **용도:** 포위망 탈출 및 보스의 치명적인 십자 탄막 회피.
- **포트리스 [절대 방벽 / Aegis Shield]**
  - **효과:** 2.5초간 기체가 멈추는 대신, 거대한 쉴드를 전개하여 닿는 모든 적 탄막을 소멸시키고 적에게 강력한 넉백과 충돌 피해를 입힘.
  - **쿨타임:** 12초
  - **용도:** 돌발 균열이나 러셔(Rusher) 떼가 몰려올 때 탱킹 및 광역 반격.
- **헌터 [시간 왜곡 / Time Dilation]**
  - **효과:** 4초 동안 플레이어를 제외한 모든 적과 적 탄막의 속도가 60% 느려짐 (슬로우 모션).
  - **쿨타임:** 15초
  - **용도:** 텔레포터나 실더가 등장했을 때 시간을 늦추고 사각(후면)으로 빠르게 돌아 들어가 폭딜.

## 3. ⌨️ 키보드 온리(Keyboard-Only) 조작 지원
**이슈:** 게임 플레이는 WASD로 하지만, 레벨업 카드 선택이나 격납고 시작 시 마우스를 강제로 잡아야 해서 조작 흐름이 끊김.

### 3-1. 인게임 UI 포커스 시스템 도입
- **대상:** 레벨업 3선택지, 크래프팅 3선택지, 게임 오버 화면, 일시정지(ESC) 메뉴.
- **작동 방식:**
  - 선택지 창이 뜨면 첫 번째 카드(Index 0)에 자동으로 **하이라이트 테두리(Focus Ring)**가 생김.
  - `A` / `D` 또는 `Left` / `Right` 방향키로 포커스를 좌우로 이동.
  - `Spacebar` 또는 `Enter`를 누르면 포커스된 카드를 선택하고 진행.
- **구현 기술:** DOM 기반 UI이므로, HTML 요소에 `.focused` CSS 클래스를 토글하거나 기본 `tabindex`와 `element.focus()` API를 활용.

### 3-2. 격납고(Lobby) 키보드 접근성
- 격납고에서도 `Tab` 키나 방향키를 통해 스테이지 -> 도전 모드 -> 기체 -> [출격] 버튼 순으로 포커스가 이동하도록 HTML 구조 최적화.
- 출격 버튼이 포커스된 상태에서 `Enter` 시 바로 게임 시작.
