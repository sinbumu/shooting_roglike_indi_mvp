# STELLAR SURVIVOR — 기획 추가 지시서 (v1.13.0 판테온 UI/UX 및 편의성 개편)

> **문서 목적:** 모바일 세로 화면에서 빽빽하게 보이던 판테온(성좌) 보드의 시인성과 조작감을 개선합니다. 카메라 줌(Zoom) 기능, 은은한 반투명 노드 이펙트, 그리고 유저가 자유롭게 빌드를 수정할 수 있는 포인트 회수(Refund) 기능을 추가합니다.

---

## 1. 카메라 내비게이션 (Zoom & Pan) (`UI.ts` 또는 판테온 렌더러)
판테온 진입 시 한눈에 전체를 보여주는 대신, 뷰를 확대하고 유저가 직접 탐색하도록 변경합니다.

- **[ ] 초기 카메라 뷰:**
  - 판테온 모달이 열릴 때, 카메라의 기본 배율(Scale)을 1.5x ~ 2.0x로 확대된 상태로 시작합니다.
  - 카메라의 중심점(Focus)을 트리의 **'시작 노드'** 또는 **'가장 최근에 투자한 노드'**에 맞춥니다.
- **[ ] 확대/축소(Zoom) 컨트롤:**
  - **PC:** 마우스 휠(`wheel`) 이벤트를 통해 카메라 배율을 부드럽게 조절합니다.
  - **UI 버튼:** 화면 우측 상단 구석에 `[ + ]`, `[ - ]` 버튼을 절대 좌표(Absolute)로 고정 배치하여 터치 환경에서도 쉽게 줌인/아웃이 가능하게 합니다.
  - *제한:* 최소 배율(전체 보기)과 최대 배율(노드 1개가 크게 보임)의 Min/Max 클램프(Clamp)를 설정합니다.
- **[ ] 패닝(Panning):**
  - 마우스 드래그나 터치 스와이프를 통해 맵을 상하좌우로 부드럽게 이동할 수 있어야 합니다.

---

## 2. 투자 가능 노드 시각 효과 개선 (반투명 글로우)
단색으로 쨍하게 빛나서 눈을 아프게 하던 기존 발광 이펙트를 세련되게 교체합니다.

- **[ ] 반투명 에셋 및 블렌딩 처리 (`Renderer.ts` / `UI.ts`):**
  - 기존의 하드코딩된 단색 렌더링 대신, 가장자리가 부드럽게 퍼지는 **방사형 그라데이션 에셋(예: `spr_node_glow`)**을 사용하거나 `PIXI.Graphics`로 그라데이션을 생성합니다.
  - **Color & Alpha:** 투자 가능한 노드의 테마 색상(Category Color)을 해당 글로우의 `tint`로 입히고, `alpha` 값을 0.3 ~ 0.5 수준으로 낮춥니다.
  - **Blend Mode:** `ADD` 블렌드 모드를 적용하여, 배경 위에 은은하고 영롱하게 퍼지는(Ethereal) 느낌을 줍니다.
  - *애니메이션:* alpha 값이 천천히 호흡하듯 점멸(Pulse)하게 만들면 더욱 퀄리티가 높아집니다.

## 3. 포인트 회수 (Refund) 시스템
잘못 찍은 포인트를 유저가 언제든 되돌릴 수 있게 하여 덱빌딩의 자유도를 높입니다.

- **[ ] 회수 모드 토글 UI:**
  - 화면 좌측 상단에 **[노드 회수: OFF]** 토글 버튼을 배치합니다. (버튼 클릭 시 ON/OFF 스위칭, 시각적으로 ON일 때 붉은색 등으로 강조)
- **[ ] 회수(Refund) 로직 (`UI.ts` / `Meta.ts`):**
  - 토글이 **ON**인 상태에서 이미 투자된 노드를 클릭하면 1포인트가 회수됩니다. (해당 노드 레벨 -1, 보유 판테온 포인트 +1)
- **[ ] 트리 단절 방지 (Prerequisite Check):**
  - **핵심:** A 노드를 선행 조건(`prereq`)으로 삼는 B 노드가 이미 투자되어 있다면, A 노드는 회수할 수 없어야 합니다.
  - 에이전트는 회수 클릭 이벤트 발생 시, *'현재 회수하려는 노드의 ID를 `prereq`로 가지며 현재 투자 레벨이 1 이상인 하위 노드가 존재하는지'* 검사하는 방어 로직을 반드시 작성해야 합니다. (존재할 경우 화면에 "하위 노드를 먼저 회수해야 합니다" 경고 텍스트 출력)
