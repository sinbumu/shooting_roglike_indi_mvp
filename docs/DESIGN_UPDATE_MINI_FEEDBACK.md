# 🚀 STELLAR SURVIVOR — 기획 추가 지시서 (초반 억까 방지 & UI/UX 폴리싱)

> **문서 목적:** 플레이어 피드백을 반영하여 초반 빌드업의 불쾌한 운(RNG) 요소를 줄이고, 게임 내 정보의 직관성 및 웹 UI의 완성도를 높입니다.

---

## 1. 🎲 초반 레벨업 '억까' 방지 (신규 무기 확정 등장)
**이슈:** 극초반 레벨업 시 기존 무기 강화나 패시브만 뜰 경우, 새로운 무기 슬롯을 채우지 못해 게임 경험이 크게 나빠짐.

### 1-1. 특정 레벨업 시 신규 무기 픽 강제
- **기능:** 플레이어의 1번째, 3번째, 5번째 레벨업(즉, Lv 2, Lv 4, Lv 6 달성 시) 3선택지 중 최소 1개는 반드시 **[신규 무기(New Weapon)]**가 등장하도록 보정합니다.
- **구현 방식 (`LevelUpSystem.ts`):**
  - 무기 슬롯이 아직 꽉 차지 않은 상태(슬롯 5개 미만)일 때 작동.
  - 현재 플레이어 레벨이 2, 4, 6일 경우, 선택지 배열(Choices)을 생성할 때 남은 기본 무기(Tier 1) 풀에서 1개를 무조건 먼저 푸시(Push)한 뒤, 나머지 2개를 기존 가중치 알고리즘으로 채웁니다.

## 2. 📊 패시브 수치 직관성 개선 (Tooltip Clarity)
**이슈:** '과충전' 등 패시브 효과가 정확히 몇 % 증가하는지 몰라 플레이어가 빌드 효율을 계산하기 어려움.

### 2-1. `GameConfig.ts` 설명(desc) 텍스트에 구체적 수치 명시
- **기능:** 추상적인 텍스트를 직관적인 수치형 텍스트로 일괄 변경합니다.
- **변경 예시 (`PASSIVES`):**
  - `overcharge`: "모든 무기 데미지 증가" ➡️ "모든 무기 데미지 **+12%** 증가"
  - `collector`: "경험치 획득량 증가" ➡️ "경험치 획득량 **+15%** 증가"
  - `plating`: "받는 피해 감소" ➡️ "받는 피해 **-8%** 감소"
  - `thruster`: "이동 속도 증가" ➡️ "이동 속도 **+8%** 증가"
- **참고:** 이미 한계 돌파(ENDGAME.stats) 쪽은 수치가 표기되어 있으므로, 기존 패시브 쪽만 톤앤매너를 맞추면 됩니다.

## 3. 🖱️ 격납고(Hangar) UI 스크롤바 버그 수정
**이슈:** Hangar 모달창 내부 요소에 마우스를 올릴 때(Hover), 미세한 크기 변화나 레이아웃 시프트로 인해 하단/우측에 불필요한 스크롤바가 깜빡거림.

### 3-1. CSS 레이아웃 및 렌더링 수정
- **해결 방안 (`style.css`):**
  - 모달창 컨테이너(예: `.hangar-modal` 또는 `.modal-content`)에 `overflow: hidden;`을 적용하여 자식 요소가 튀어나오며 스크롤을 유발하는 것을 방지.
  - Hover 시 `transform: scale(...)`이나 `border` 추가로 인해 요소의 전체 너비/높이가 변하는 경우, 레이아웃 변화가 없도록 `box-sizing: border-box;`를 점검하거나 여백(margin/padding)을 조정.
  - 모달에 스크롤이 꼭 필요한 구조라면 `overflow-y: auto; overflow-x: hidden;` 처리.
