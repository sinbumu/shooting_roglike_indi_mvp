```

  → 오메가·스타폴·제네시스 / 템페스트·파열핵·솔라랜스·해머딘

근접·장판 T1            T2                              T3
⚔️ 블레이드 / 💣 지뢰
  → 톱날·빔소드 / 추적지뢰·특이점
  → 후광·절단기 / 프레데터·이벤트 호라이즌

매트릭스 T1             T2                              T3 (패시브 촉매, 미소모)
🌀 채찍 / 🕷️ 스파이더 / 🩸 핏빛 쐐기
  → 궤도톱·유도참격·진동채찍
  → 요격기·포탑·톱니드론
```

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # → dist/
npm run preview
```

## 배포

- `main` push → GitHub Actions → **GitHub Pages** 자동 배포.
- Settings → Pages → Source를 **GitHub Actions**로 둔 상태여야 합니다.

## 기술 스택

- Vite 5 + TypeScript strict + PixiJS v8 + DOM UI + Web Audio (프로시저럴, 외부 음원 없음)
- 스프라이트: `public/assets/sprites/` (기체·적·보스·픽업·무기 FX PNG)

## 아키텍처

```
src/
├── GameConfig.ts    # ★ 밸런스·콘텐츠 데이터 (기획 실험의 주 무대)
├── types.ts
├── PatchNotes.ts    # 인게임 체인지로그 (최신이 index 0)
├── assets.ts        # 스프라이트 경로·로드
├── GameState.ts     # 게임 로직
├── Renderer.ts      # PixiJS (전투는 읽기 전용, events만 소비)
├── Audio.ts
├── LevelUpSystem.ts # 3선택지
├── UI.ts            # 격납고·HUD
├── Meta.ts          # 로컬 세이브
├── main.ts
└── style.css
```

로직 / 렌더 / UI 분리. 수치 변경은 대부분 `GameConfig.ts`만으로 가능합니다.
